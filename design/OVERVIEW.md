## 0. ひとことで

- 上から見る 2D の車のレース。ブラウザで遊ぶ (iPhone・Android・Mac)。スマホは縦でも横でもよい。
- 7×11 のマス目に部品を並べて自分の車を作り、ネットで大勢 (1 レース 8 台まで、足りない分はコンピューター) と走る。
- 1 人 = 1 チーム。自分が運転し、2 台目はお金で雇うコンピューターの運転手。
- 毎週の季節 (級 5 つ)、毎日 22:30 の大会、2 時間ごとに自動で走るリーグ戦 (部 8 つ) がある。
- 見た目は「F1 中継風」(暗い画面にくっきりした文字と色、テレビの順位表のような表示)。絵と音は全部プログラムで作る (外の素材なし)。
- 画面は TypeScript + Canvas 2D (React なし)。サーバーは Cloudflare Workers + Durable Objects。
- 嵐の環 (となりの別のゲーム) とは別のゲーム・別のリポジトリ・別の Cloudflare アカウント。

## 1. ゲームの形と遊び方

### 1.1 画面の流れ

```
オープニング ─┬─ (ログインあり) ─────────────→ メニュー
              └─ (ログインなし) → ログイン / 登録 ─→ メニュー
                                   └ 「ログインしないで試す」→ メニュー (記録はこの機械だけ)
```

- ゲームを開くとオープニング。押すと飛ばせる。
- この機械にログインが残っていれば、ログインの画面は飛ばす。
- 「ログインしないで試す」を選ぶと、そのタブを閉じるまでログインの画面に戻さない。試すだけの人は 賞金・走行点・季節・リーグ戦・賭け・交換所 に入れない。
- 画面の途中で読み直すと、同じ画面に戻る (sessionStorage の `bpr.screen`)。

メニューは 3 つに分けてある。

- **走る**: すぐ走る・部屋・練習・みんなのコース・1 周アタック・リーグ戦・季節と大会
- **チーム**: チーム・運転手・研究・市場・お店・交換所・アカウント
- **設定**: 操作・変速・音・オープニング・ギフトコード

車がなければメニューの一番上に「まず車をつくる」、走れない車なら「車を仕上げる」とわけを出す。

| 画面 | ファイル (`web/src/ui/`) | 中身 |

### 1.2 操作

操作は設定で選ぶ。

- **ふつう**: ハンドル・アクセル・ブレーキを自分で。
- **かんたん**: アクセルは自動。曲がりの手前で自動でブレーキ。
- **変速**: オートマ / マニュアル。マニュアルはパソコン (キーボード) だけで選べる。スマホでは出さない。

| 動き | キーボード | スマホ |
|---|---|---|
| 曲がる | ← → (A D) | 左下の ◀ ▶ (指をすべらせて切りかえ) |
| アクセル | ↑ (W) | 右下のアクセル (かんたんでは出ない) |
| ブレーキ | ↓ (S・スペース) | 右下のブレーキ。止まっているとき押し続けると下がる |
| DRS | E | 計器の右上のボタン |
| オーバーテイク | Q (押している間) | OT のボタン |
| ピットの予約 | P (札の中で Enter で予約・Esc で閉じる) | PIT のボタン |
| 無線のすすめを受ける | R | カードの「そうする」 |
| ギアを上げる / 下げる (マニュアル) | X か Shift / Z か Ctrl | — |

- スタートは信号が全部消えたら。早すぎるとフライングで +5 秒。
- 練習と 1 周アタックの信号は 2 倍速 (約 3 秒)。
- 通信が切れたら、コンピューターが代わりに運転する。つなぎ直せば続きから自分で走れる。

### 1.3 見た目と言葉

- F1 中継風。字体は Barlow Condensed と Noto Sans JP (Google Fonts)。本物の放送のロゴや字体は写さない。
- 車とコースは線と図形でプログラムが描く (`web/src/draw.ts`・`web/src/race/trackdraw.ts`)。
- 自分の車は自分の色に白い縁と白い光。幽霊は半透明。部品の種類ごとに色がある (運転席 赤・エンジン 橙・タイヤ 薄い灰・燃料タンク 黄・羽根 水色・ブレーキ 紫・骨組み 灰)。
- 言葉は日本語。あとで増やせるよう、言葉は別の表にまとめる方針 (まだ全部はまとまっていない)。

## 2. 仕組みごとの決まり

### 2.1 車づくり

**マス目と部品**

- マス目は横 7 × 縦 11 (縦が前後)。1 マス 0.4 m。全員同じ広さ (`shared/src/design.ts`)。
- 部品には 形 (占めるマス)・段階 (1〜5)・性格 がある。90 度回して置ける。左右対称でなくてよい。
- 走れる条件 (`validateDesign`):
  - 運転席がちょうど 1 つ・エンジンと燃料タンクが 1 つ以上
  - タイヤが 2 つ以上で、前と後ろが 3 マス以上離れている
  - はみ出し・重なりがない
  - 全部の部品が運転席から上下左右にたどれる
- 走りに効くもの: 全体の重さ・重心の前後の偏り・タイヤの位置と数・エンジンからタイヤまでのつながり・羽根の押しつけと空気の抵抗・ブレーキの強さ。運転席は前にあるほど曲がりの反応がよい。
- 燃料 1 L = 0.75 kg。満タンほど重い。部品は使っても古くならない。

**部品の種類**

| 種類 | 何に効くか | 手に入れ方 |
|---|---|---|
| 運転席 | 必ず 1 つ。壊れるとリタイア | お店 |
| 骨組み | 部品どうしをつなぐ | お店 |
| エンジン | 力 (kW)・燃料の食い方 | お店 (段階 1〜2)・研究 (3〜5) |
| タイヤ | 握り・特徴 (下の表) | 同上 |
| 燃料タンク | 容量 (L) | 同上 |
| 羽根 | 押しつけ (曲がり) と空気の抵抗 | 同上 |
| ブレーキ | 止まる力 | 同上 |
| 冷却 | 燃料の食い方を減らす (5〜12%) | 研究だけ |
| 電池 | オーバーテイクの目盛りを増やす (+1.5〜4 秒) | 研究だけ |
| ギア箱 | マニュアルの上がり分を増やす (+1〜2.2%) | 研究だけ |
| サスペンション | 縁石と芝で握りが落ちにくい (25〜50%) | 研究だけ |
| 重り | 重心を動かす (10〜30 kg) | 研究だけ |

- お店の部品は 16 種 (`shared/src/parts.ts`)。研究の部品は 47 種 (`research.ts`)。進化でだけできる部品が 11 種 (`evoparts.ts`)。
- 新しい種類 (冷却〜重り) は重ねても上限がある (`DEV_CAPS`)。
- はじめの部品の箱 (段階 1): 運転席 1・骨組み 14・小型と中型のエンジン 各 1・細いタイヤ 4・太いタイヤ 2・小さいタンク 2・大きいタンク 1・小さい羽根 2・ブレーキ 2。最初の 1 台は自分で組む。

**タイヤの部品の特徴** (`shared/src/tires.ts` の `TIRE_TRAITS`)

- 長持ち・食いつき・雨に強い・縁石に強い・破裂しにくい・曲がりに強い・ブレーキに強い の 7 つ。良い所と悪い所の組。
- 段階が上がるほど、良い所が大きく、悪い所が小さい。
- お店のタイヤ: 細い = 破裂しにくい・太い = 食いつき・軽い = 曲がりに強い。研究のタイヤで残りの特徴と強い版。
- タイヤの種類 (柔らかい〜大雨用) とは別のもの。掛け合わせで効く。

**試走台と改訂番号** (`shared/src/bench.ts`・`web/src/store.ts`)

- 部品を置くたびに、最高速・半径 30 m の曲がりの速さ・1 周の燃料・公式コースの 1 周の見込みを出す。前の形との差を緑と赤で。
- 1 周の見込みは、一番上手なコンピューターが普通のタイヤ・満タンで 2 周走った 2 周目。
- 走れる形を版 (Rev.A・Rev.B…Z・AA…) として残す。1 つの設計図に 26 版まで。古い物から消す (一番速い周を持つ版は残す)。晴れの練習の一番速い周を版ごとに覚える。

**設計図の持ち方**

- 設計図はいくつでも (サーバーには 1 人 50 まで)。部品の箱の数は設計図 1 つごとに数える (設計図どうしで取り合わない)。
- ログインしていれば、設計図をサーバーと合わせる (`web/src/designsync.ts`)。保存の 2 秒後に送る。両方で直したら新しい方。この機械の物は消さない。

**部品の進化** (`shared/src/evolution.ts`)

- 持っている部品 1 つを、お金 + 要る研究 で 1 つ上の部品にする。道は 73 本。枝分かれ (力寄り / 燃費寄り・軽さ寄り / 頑丈 など) があり、形が変わる物もある。
- 値段 = 種類のもと × 段の倍率 (段階 2: 1.5・3: 3・4: 6・5: 12)。
- 頑丈な部品は当たっても傷みにくい。

**研究の木** (`shared/src/research.ts`)

- お金を入れて時間を待つと、新しい部品 (段階 3〜5) を作れるようになる。寝ている間も進む。同時に 1 つ。
- 段階 3 はお店の部品から、4 は 3 から、5 は 4 から。
- お金 / 時間: 段階 3 = 2,000 / 6 時間・4 = 10,000 / 18 時間・5 = 30,000 / 48 時間。
- 元の部品を付けて走ると早く進む (1 km で 10 分、待つ時間の半分まで)。
- できた部品は 1 個ずつお金を払って作る (1 回 50 個まで)。

**限界突破の品** (`shared/src/items.ts`・`evoparts.ts`)

- **限界設計図**: 段階 5 の部品を 5+ → 5++ に (1 つの部品に 2 回まで、1 回で主な強さ +4%)。
- **特別指導書**: 雇った運転手の育つ上限を能力ごとに +5 (100 まで、1 人に 2 回まで)。
- かけら 10 個で 1 つ (限界突破のかけら → 限界設計図・指導のかけら → 特別指導書)。
- 手に入るのは景品・交換所・ギフトコードだけ。お店では買えない。市場でも売り買いできない。コンピューターのチームは使わない。

### 2.2 走り (車の動きとハンドル)

`shared/src/physics.ts` (1 刻み = 1/60 秒)。

- 入力はハンドル・アクセル・ブレーキ。握りを超えると滑る。
- ハンドル (キーとボタン): 0.07 秒でいっぱいまで切れ、0.05 秒で戻る。いっぱいに切ったときの回る速さは 1.6 倍。
- 切れ角の上限は速さで変わる (遅いとき 4.5 倍・速いとき 4.2 倍の握り)。
- 「回りすぎ止め」: 鼻先が進む向きより 15° (遅いとき)〜6° (速いとき) 以上は内へ向かない。押し続けてもくるっと回らない。
- 芝: 速さに比例して遅くなる。止まった所からは必ず抜け出せる。
- 縁石: 乗ると近道できるが、タイヤが 1.5 倍減る。
- コースの外を通って近道すると、その周は数えない + 罰 (3 秒 + 近道した距離 ÷ 20)。
- かんたん操作: コンピューターと同じ見積もりで、曲がりの手前で自分でブレーキ。曲がりの中の自動ブレーキは「実際に滑る角」で効く。
- ゴールしたあとは、ゆっくりコースに沿って走る (時速 54 km まで)。
- 車どうしはぶつかる (`collide.ts`)。ゴール・リタイアした車とピットの道の車はすり抜ける。
- カメラは車の向きに合わせて回る (車はいつも上向き)。スマホの縦は近くに寄せる。

細かい数の変わり方 (1 周のタイム・曲がりの角度) は DECISIONS の「曲がりを良くした」の項。

### 2.3 タイヤとタイヤの組

**種類** (`shared/src/tires.ts`)

| 種類 | 記号 | 性格 |
|---|---|---|
| 柔らかい | S | 一番握る。早く減る |
| 普通 | M | 真ん中 |
| 硬い | H | 長持ち。握りは低め |
| 小雨用 | I | 濡れた路面用。乾いた路面ではすぐ減る |
| 大雨用 | W | びしょびしょの路面用。水たまりに強い |

- 走るとすり減り、減るほど握りが落ちる。限界を超えると破裂 (とても遅く、ピットまでゆっくり戻る)。
- 青図サーキットで 柔らかい 約 3 周・普通 約 5 周・硬い 約 7 周で破裂する。長いコースでは早い (鈴鹿の柔らかいは約 1.4 周)。
- 75% 減ったら知らせる。破裂したら大きく知らせる。

**持っていくタイヤの組** (`shared/src/tireset.ts`)

- 走る前に、そのレースに持っていく組を決める (例: 柔らかい 2・普通 1)。レース中はその中からしか履けない。
- 組の数: 2 周 → 2 組・5 周 → 3 組・10 周 → 4 組。大会と開いた部屋は 周 ÷ 3 + 1 (切り上げ、最大 8)。予選があるときは +2。練習は決まりなし。
- 外したタイヤは「使った組」として減りを覚え、あとでまた履ける。破裂した組・使い切った組は捨てる。
- 雨用を入れるかは自由。入れずに雨が来たら乾いたタイヤのまま走る (「雨用なし」と出す)。
- 大会では乾いた路面用を 2 種類以上入れないといけない。
- 「おまかせ」ではコンピューターが組を決める。予報で濡れ具合 0.3 以上が見込まれると雨用を 1 組 (0.7 以上なら大雨用)。
- 天気が変わって、その天気用をまだ選んでいなければ、合うタイヤを自動で選ぶ。

### 2.4 天気と乾く線

`shared/src/weather.ts`。

- 天気は 晴れ・小雨・大雨。レースの途中でも変わる。レースごとに種から予定を作る (画面とサーバーで同じ予定)。
- 路面の濡れ具合 (0〜1) は空に向かって少しずつ動く。降り始めはまだ滑らず、止んでもしばらく濡れている。
- 濡れ具合 0.55 から水たまり。
- 雨のあとは、みんなが走る線から 2.5 倍の速さで乾く (線から 1.2 m までは同じ速さ)。
- 予報が出る (「N 周あとに雨 70%」のように)。外れることもある。予報は 240 秒先まで。
- 練習は天気を選べる (晴れ・小雨・大雨・変わる)。1 周アタックと予選はいつも晴れ。

### 2.5 ピット

`shared/src/pit.ts`。

- 「次の周で入る」を予約すると、入り口で自動で入る。入り口の線を越えるまでは取り消せる。
- ピットの道は制限速度 (秒速 16 m) で自動で走る。燃料は減らず、ほかの車とぶつからない。
- 止まる場所でタイヤ・燃料・修理を同時にする。一番長いものの時間だけ止まる。止まっている間に中身を変えられる。
  - タイヤ: 1.5 秒 + タイヤの部品 1 つにつき 0.6 秒 (タイヤの多い車ほど長い)
  - 燃料: 1 L で 0.2 秒
  - 修理: 1 秒 + 傷 1 つ 1.5 秒 + 落ちた部品 1 つ 2.5 秒
- 整備の組の腕で時間が短くなる (一番よくて 0.6 倍)。
- **2 台の順番待ち**: 同じチームの 2 台が同じときに来たら、後の車は止まる場所の 8 m 手前で待つ。
- 2 台目のピット: 走る前の予定 + 運転手自身の判断 (天気など)。人が無線の合図で「ピットに入れ」と送れば、それが先。
- 傷はレースのあとに自動で直る。
- 先導車 (SC) の間に入ると得をする (F1 と同じ)。

### 2.6 DRS・風よけ・オーバーテイク

**DRS** (`shared/src/drs.ts`)

- 決まった区間の手前の検知の線で前の車と 1 秒以内なら、その区間でボタン (E) を押すと空気の抵抗が 0.75 倍。
- 1 区間 1 回。ブレーキか区間の終わりで閉じる。
- 押すと燃料 0.15 L とタイヤが少し減る。
- 使えないとき: 1 周目・旗のあと 15 秒・濡れ具合 0.3 以上。
- 区間はコースごと。書かなければ長い直線から自動で決める。

**風よけ (スリップストリーム)**

- どの車でも、前の車の 2.5〜28 m 後ろ・横 2.2 m 以内・時速 50 km 以上で、空気の抵抗が最大 0.2 減る。

**オーバーテイクモード** (`shared/src/overtake.ts`)

- DRS とは別。DRS は空気の抵抗を減らす (まっすぐで速い)、オーバーテイクはエンジンの力を足す (+20%、立ち上がりで速い)。
- スタートの線で前の車と 1 秒以内なら、次の 1 周に使える。1 周に 5 秒分の目盛り (電池の部品で増える)。押している間だけ減る。周をまたいで持ち越さない。
- 使うと燃料とタイヤが少し多く減る。1 周目と旗のあと 15 秒は使えない。雨でも使える。
- コンピューターと代走も使う。

### 2.7 ギアとマニュアル

`shared/src/gearbox.ts`。

- 車に 7 段のギアがある。オートマはいつも一番よい段に入っているとみなす (速さは前と同じ。段と回転は画面と音のためだけ)。
- マニュアル (パソコンだけ) で走ると、車の速さ (最高速と加速) が 3% 上がる (管理者が 0〜30% で変えられる)。上手に変えると 1 周 0.4〜1.3% 速い。
- 回しすぎると力が頭打ち、段が高すぎて回転が低いと加速が鈍い。下手だとオートマより遅くなることもある。
- 回転の目盛りは 94% で青く光り、上限で赤。結果と 1 周アタックの記録に AT / MT の印。
- コンピューターと代走はオートマ。

### 2.8 旗・SC・VSC・罰

`shared/src/racecontrol.ts`。部屋が毎刻み動かす。

| 出来事 | 出るもの | 中身 |
|---|---|---|
| 強い当たり (12 m/s 以上) | 黄旗 | コースを 10 区間に分け、その区間に 12 秒。抜くと 5 秒の罰 |
| 車が 3 秒以上止まった・燃料切れ | VSC | 22 秒。全員 時速 72 km まで。差はそのまま。追い越し禁止 |
| 部品が落ちた・大雨に変わった | SC (先導車) | 先頭の 70 m 前に出て 25〜80 秒。間隔 12 m で一列に自動で走る。先頭がスタートの線を越えたら再開 |

- 壊れた車・ピットの道の車・ずっと遅い車を黄旗で抜いても罰なし。
- チェッカーのあとは SC を出さない。
- 罰: フライング 5 秒・近道 (3 + 距離 ÷ 20) 秒・黄旗で抜く 5 秒。

### 2.9 傷みと当たり

`shared/src/damage.ts`。

- 壁に 6 m/s 以上・車どうし 4 m/s 以上でぶつかると、当たった所に近い部品が傷む。
- 傷んだ部品は働きが落ちる (羽根 → 曲がりにくい・タイヤ → 握り・エンジン → 力・ブレーキ → 効き)。燃料タンクと骨組みは当たりを受け止めるだけ。
- 壊れきった部品にまた強く当たると外れて落ちる (重さと重心も変わる。SC が出る)。
- 運転席が壊れたらリタイア。燃料が切れてもリタイア。
- 練習でも傷む。ピットで直せる。レースのあとは自動で直る。
- 計器の小さな車の絵で傷みを見せる (白 = 無事・橙 = 傷・赤 = 壊れ・赤の点線 = 落ちた)。

### 2.10 レースの画面の表示

- **順位の塔**: 順位・名前・タイム差・今のタイヤ (色の丸と S/M/H/I/W)・そのタイヤの周・ピットの回数・セクターの 3 色の帯。押すと「前との差」と「先頭との差」を切りかえ。スマホでは上位 3 台と自分の前後だけ (押すと全部)。
- **タイム差** (`timing.ts`): コースを 25 m ごとに区切った印を通った時刻の差。前と後ろの車のカードに ▲▼ と色。
- **セクター** (`sectors.ts`): 1 周を S1・S2・S3 に分ける。自分の一番 = 緑、その場の全員で一番 = 紫、遅い = 黄。切れ目はコースごと (書かなければ 3 等分)。黄旗の 10 区間とは別のもの。
- **無線の作戦係** (`radio.ts`・`web/src/race/radio-ui.ts`): 作戦係がカードで知らせる (燃料・タイヤの減り・雨の予報・VSC はピットのチャンス・DRS 圏内・最後の周 など)。急ぎが先。ピットのすすめは「そうする」(R) で予約できる。
- **走った線** (`replay.ts`・`replay-ui.ts`): 0.1 秒ごとに覚え、今の周と前の 3 周を残す。速さで色分け、ブレーキは赤、一番速い周は紫。練習は地図の下、ネットのレースは結果の札に。
- そのほか: 天気と予報 (右上)・タイヤの減りと燃料「あと何周」・小さな地図 (黄旗の区間と先導車)・DRS のボタン (OFF・差・READY・OPEN)・旗の帯・名札 (DRS と「!」)。
- **2 台目への作戦の合図** (`teamorder.ts`): ピットに入れ・タイヤを持たせろ・攻めろ・前を譲れ。

### 2.11 レースの進み方 (部屋)

`shared/src/room.ts`。部屋の段階は `idle → lobby → race → results → lobby …`。

- 待合 (GRID) 12 秒 (開いた部屋は 90 秒)。遅れて入った人のために、残りが 10 秒より少なければ 10 秒まで延ばす (もとの終わりから 20 秒まで)。
- スタートの並びは **くじ** (人もコンピューターも 8 つの場所全部)。大会だけは予選の順。
- 先頭がゴールしたら、その周で全員終わり (周回遅れはその周を走り終えたらゴール)。残りは最大 60 秒待つ。
- 結果 (RESULT) は 25 秒。1 位は合計時間、ほかは差。最速の周は紫。
- 空きはコンピューターが埋める。強さは級ごとにばらつく (`matchmaking.ts` の `CPU_SKILL_RANGE`)。コンピューターの車は人と同じ はじめの部品の箱の車。
- 雇った運転手がいると、2 台目が一緒に出る (8 台がうまっていたら 1 台目だけ)。2 台目の車はチームの画面で選んだ設計図。
- レース中に人が全員切れても、コンピューターの代わりの運転で続く (60 秒たっても戻らなければ止まる)。

### 2.12 点

`shared/src/race.ts`。

- 決まり (ユーザー): 1 位は 25 点。最下位とその 1 つ上 (下から 2 台) は 0 点。
- 間は 18・15・12・10・8・6・4・2・1 を上から順に使う (仮)。

| 台数 | 点 |
|---|---|
| 8 台 | 25・18・15・12・10・8・0・0 |
| 7 台 | 25・18・15・12・10・0・0 |
| 6 台 | 25・18・15・12・0・0 |
| 5 台 | 25・18・15・0・0 |
| 4 台 | 25・18・0・0 |
| 3 台以下 | 1 位 25、ほかは 0 |

- 台数は完走できなかった車も数える。完走できなかった車と失格は 0。
- 一番速い周に 1 点。ただし点の入る順位で完走したときだけ。同じタイムなら先に出した方。
- 普段のレース・大会・リーグ戦、全部同じ並び。重みは季節の項 (2.15)。

### 2.13 普段のレース (すぐ走る・部屋)

- **すぐ走る**: 短い (2 周)・普通 (5 周)・長い (10 周) を選び、同じ級・同じ長さを選んだ人と組む。ログインしていなければ 5 級。級のちがう部屋には入れない。
- **部屋**: 開いた人がコース (公式 + みんなのコース)・周 (1〜30) を決める。級は開いた人の級だけ。合言葉なし。
  - 人が 2 人以上なら、開いた人が「今すぐスタート」できる。
  - 1 人 1 部屋まで・全体で 50 部屋まで。誰も来ない部屋は 3 分で消える。退会した人の部屋はすぐ消える。
  - 結果は季節に入る。
- 賞金 = (点 × 20 + 完走 30) × 周の倍率 (2 周 ×1・5 周 ×1.75・10 周 ×3。式は 0.5 + 周 × 0.25)。人が自分だけのレースは半分。
- レースでお金はかからない (タイヤ・燃料・出場料なし)。

### 2.14 練習と 1 周アタック

**練習** (`web/src/ui/practice.ts`)

- ネットなしで一人で走れる。自分の一番速い周が幽霊になって一緒に走る (幽霊は晴れのときだけ記録)。
- 天気を選べる。タイヤの組の決まりはない。走った線を開いている間は止まる。
- みんなのコースも練習で走れる (走り終えると「いいね」を押せる)。
- 練習の賞金は数の調整に数だけある (コードではまだ払っていない。5 章)。

**1 周アタック** (`shared/src/timeattack.ts`・`server/src/timeattack.ts`)

- 毎週 (月曜 0 時、日本時間) お題のコース。公式コースを順に回す。
- 条件はいつも同じ: 晴れ・柔らかいタイヤの新品・満タン。1 回の走りは 3 周まで、一番速い周を残す。PIT のボタンは出さない。
- 順位表は上位 20。幽霊は上位 5 人から 3 台まで選べる。幽霊は決まった見本の車の形で描く (相手の設計図は見せない)。
- ずるの確かめ: 車の性能から出せる一番速いタイムより速い周・幽霊の動きが速すぎる・コースから外れすぎ・長さが合わない、は受けない。1 時間に 120 回まで。週が変わって 10 分は前の週にも出せる。マニュアルの上がり分も見込む。
- 週の 1 位に限界設計図 1 つ。ログインしていなければこの機械の中だけ。

### 2.15 季節と級

`shared/src/season.ts`・`server/src/season.ts`。

- 季節は 1 週間。月曜 0 時 (日本時間) から。最初の季節は 2026-11-30。名前は「第 N 季」(始まる前は「準備の季節」)。
- 級は 5 つ (1 級が一番上)。チームに付く。普段は同じ級どうしで走る。大会は級なし。
- 季節の点の重み: 普段のレース ×1・大会 ×10・人のチームが 1 つだけのレース ×0.5。
- 順位は 2 つ: チーム順位 (2 台の合計) と運転手順位 (自分の点だけ。雇った運転手も入る)。
- 代走の点: チームにはそのまま入る。運転手順位には、普段のレースとリーグ戦では入らない。大会では 1/5 を切り捨ててから ×10 (25 → 5 → 50 点)。
- 同点: 点 → 大会の点 → 1 位の回数・2 位の回数… → 先にその点に届いた方。
- **上がり下がり** (11/25 ユーザー「昇格できるチームを 1 チームに」): 各級で 1 位の 1 チームが上へ、最下位の 1 チームが下へ (下がるのは仮)。級に 1 チームしかいなければ上がる (下がらない)。
- 新しいチームは最初の季節は級なしで、5 級に混ざって走る。5 級の 1 位なら次は 4 級、ほかは 5 級。
- 季節の締めの順: チャンピオン → 級の入れ替え → 季節の賞金 (1 回以上走ったチームだけ) → チャンピオンの賞金 → はんこ → 記録 → 知らせ → 点を 0 に → 表示名を変えられる。サーバーが寝ていたら、締めそびれた季節を 1 つずつ締める。
- 季節の賞金: 級の中の順位 30,000・20,000・15,000… 2,000 × 級の倍率 (1 級 3・2 級 2・3 級 1.5・4 級 1.2・5 級 1)。上の級ほど多い。
- 部品とお金は全部持ち越し。点だけ 0 に。

### 2.16 大会

`shared/src/tournament.ts`・`dailytour.ts`・`tourprize.ts`・`tourgrid.ts`・`server/src/season.ts`。

**毎日の大会** (11/25 ユーザー「毎日夜 10 時 30 分」「全員強制参加」)

- 毎日 22:30 (日本時間) に自動で開く。申し込みは要らない。全チームの 2 台が出る。
- その時につないでいる人は自分で走り、いない人の車は代走 (上手さ 0.8)。22:20 の前 15 分に大会の画面を開いていた人を「つないでいる」とみなす。
- 10 周。天気はくじ (予報あり)。コースは公式コースを日ごとに順に。
- 格: 月〜土は「中」、日曜は「大」。
- 予選: 前の日の大会のスタートの 30 分後から 当日 22:00 まで。いつも晴れ。何度でも走れる (1 時間に 60 回、1 回 3 周まで)。
- 予選のタイヤ: 持っていく組を予選の前に決め (最初の予選の走りで決まり、あとは変えられない)、予選と決勝を通してその組だけ。予選で減ったタイヤは決勝に持ち越す。
- 並び: 予選の順。予選を走らなかった車はその後ろに、一番後ろから強い順 (一番強い車が一番後ろ)。強さ = 試走台の 1 周 × (1 + 0.25 × (1 − 上手さ))。
- 8 台ずつの組 (A 組 = 予選 1〜8 位、B 組 = 9〜16 位 …)。大会の順位は A 組の 1〜8 位 → B 組 … の順。点は全体の順位で。
- 組の部屋は 22:20 (スタートの 10 分前) に開く。人のいない組はサーバーで速く計算して結果だけ残す (1 組ずつ、上の組から)。
- 雇った運転手がいないチームの 2 台目は埋め合わせの車 (チームの点だけ)。
- 知らせは 1 時間前だけ。
- 管理者が作った大会がある日は、自動の大会は開かない。

**管理者が作る大会**

- 名前・日時・コース・周 (1〜60)・天気・組の大きさ (2〜8)・格・景品・全員参加かを決める。
- 予選は作った時から当日 0 時まで (最低 6 時間)。
- 来ない人は代走 (予選の持ち越しタイヤと決勝の予定で)。組にコンピューターは足さない。
- 結果は全部の組がそろうか、締め切り (スタート + 周 × 4 分 + 15 分) で決める。

**大会の決まり**

- 乾いた路面 (濡れ具合 0.1 未満) では、乾いた路面用のタイヤを 2 種類以上使う (最低 1 回ピット)。守らなければ失格。完走した車だけに当て、一度でも濡れた路面を走ったら免除。
- 代走とコンピューターも、2 種類目に替えにピットに入る。

**賞金と景品**

- 賞金 (全体の順位、チームの 2 台とも): 10,000・7,000・5,000・4,000・3,000・2,000・1,500・1,000。
- 景品 (格ごとのはじめの物。管理者が大会ごとに変えられる):

| 格 | 1 位 | 2 位 | 3 位 | 参加賞 (完走) |
|---|---|---|---|---|
| 大 | 限界設計図 1 | 限界突破のかけら 5 | かけら 3 | 走行点 50 |
| 中 | かけら 5 | かけら 2 | かけら 2 | 走行点 30 |
| 小 | お金 8,000 | お金 3,000 | お金 3,000 | 走行点 20 |

- 代走も景品をもらう。失格と完走できなかった車はなし。

### 2.17 リーグ戦 (2 時間ごとの自動のレース)

`shared/src/league.ts`・`scheduled.ts`・`leaguerace.ts`・`rivals.ts`・`server/src/league.ts`・`league_do.ts`。

- 日本時間の 0・2・4…22 時に、サーバーが自動でレースを開く。**人は運転しない**。本人の車は代走 (上手さ 0.8)、2 台目は雇った運転手。
- 本戦 (季節の級) とは別枠。点は季節の点に入らず、リーグ戦の順位表 (チームごと) にだけ入る。級の上がり下がりにも効かない。
- 1 リーグ = 4 チーム (8 台)。人 2 チーム + コンピューターのチーム 2 つ。人が足りないリーグはコンピューターで埋める。
- 部は 1 部〜8 部。新しい人は 8 部から。人が増えたら同じ部に B リーグ (C…) を足す。
- 1 レース: リーグの 4 チームが全員一緒に。5 周。並びはくじ (レースの番号から作る種なので、いつ計算しても同じ)。コースは公式コースを順に。
- **1 日の締め**: 0 時〜22 時の 12 レース。22 時のレースのあとに締める。順位 = その日の点の合計 → 勝った数 → 最後のレースの結果。点は毎日 0 に戻る。
- **入れ替わり (毎日、原則 2 名)**: 部の境ごとに、上のリーグの人の下の方が下へ、下のリーグの人の上の方が上へ。1 部の一番上と 8 部の一番下は動かない。B リーグがあるときは A↔A・B↔B、なければ A へ (細かい決まりは DECISIONS「1 部から計算」)。
- **称号**: 部ごとに 1 つ。上から 技術監督 (1 部)・技術部長・主任設計技師・上級設計技師・設計技師・設計助手・製図工・製図見習い (8 部)。チーム名の横に出す。季節の最後の称号を記録に残す。
- **王者**: 日の締めで 1 部の 1 位だった人が、次の締めまで「王者」(技術監督の上)。いつも 1 人。1 部が分かれたら点の合計で比べる。コンピューターはならない。金の枠で目立たせる。7 日続けて守ると特別指導書 1 つ。
- **賞金**: 毎日、各リーグの人のチームの上位 2 (1 位 300・2 位 150) × 部の倍率 (1 部 1.0 〜 8 部 1.7)。**下の部ほど多い** (追いつけるように)。1 回ごとの賞金はない。
- 週の 1 位 (リーグ戦) に特別指導書 1 つ。週のはんこは「その週に届いた一番上の部」。
- **計算の順** (11/25 ユーザー「1 部から計算」): 1 部 → 8 部 (同じ部は A → B)。1 回の alarm で 1 レース。刻みは 1/20 秒 (1/60 秒との差は 1.5% 以内)。次の枠までに終わらなければ残りを先に。2 枠 (4 時間) 以上遅れた残りは「計算できなかった」(点も賞金もなし)。
- 結果は 14 日残す。見られるのは自分のチームの出たレースだけ。
- 止められた人のチームは出ない (席は残る)。
- リーグ戦のレースも、運転手の育ち・整備の腕・研究の進みに数える。走行点は入らない。

### 2.18 チャンピオン (季節ごと)

**コンストラクター** (`shared/src/constructors.ts`)

- チームの点 = 本戦 (普段のレース + 大会) のチーム合計 + リーグ戦の点 × 重み 0.1 × その日にいた部の倍率 (1 部 2.0・2 部 1.7・3 部 1.4・4 部 1.2・5 部 1.0・6 部 0.75・7 部 0.5・8 部 0.3)。
- 級ごとのチャンピオン 5 チーム + 総合のチャンピオン 1 チーム。リーグ戦の部ごとのチャンピオンは作らない。コンピューターのチームはならない。
- 級は季節の終わりの入れ替えの前の級。級なしは 5 級で争う。同点は本戦の点が多い方。
- 賞金: 級ごと 5,000 × 級の倍率 (1 級 4・2 級 3・3 級 2・4 級 1.5・5 級 1)、総合 40,000。景品: 級 限界設計図 1・総合 2。
- 総合のチャンピオンは、次の季節の終わりまで珍しい運転手を 1 人ただで雇える。

**ドライバーズ** (`shared/src/driverchamps.ts`)

- 級ごとに 1 人 + 総合 1 人。点は本戦だけ (リーグ戦と 1 周アタックは入れない)。代走の点は入れない (大会の 1/5 は入る)。
- 雇ったコンピューターの運転手も同じ順位で争い、チャンピオンになれる。なったら育つ余地が能力ごとに +5。
- 季節の途中で契約が変わっても、点は運転手についていく。賞金は季節の終わりにいるチームへ。
- 賞金: 級ごと 2,500 × 級の倍率、総合 20,000。景品: 級 特別指導書 1・総合 2。

### 2.19 チーム・運転手・整備

`shared/src/team.ts`・`drivers.ts`・`drivercatalog.ts`・`crew.ts`・`server/src/team.ts`。

- 1 人 = 1 チーム。遊ぶ人どうしではチームを組めない。
- チームが持つもの: 紋章 (形 6・印 10・色) ・2 台の設計図・整備の組・研究・財布。
- **雇う運転手** (2 台目):
  - 能力 4 つ: 速さ・安定・タイヤと燃料の扱い・ピットの判断。15〜80。育つ上限 (伸びしろ) は運転手ごと。年齢と引退はない。
  - 候補は全チーム共通・早い者勝ち。空きはいつも 8 人以上。
  - 人数: 雇える人 80 (作りものの名前 40 + 名簿 40) と 珍しい人 6 (季節のごほうびとギフトコードでだけ会える)。
  - 得意 8 つ (0〜2 個): 雨に強い・予選が速い・タイヤを持たせる・追い抜きがうまい・守りが固い・縁石がうまい・スタートがうまい・燃費がよい。
  - 性格 (タイヤと燃料の扱い・ミスの多さ) を 2 台目・大会・リーグ戦で効かせる (0.5〜1.5 倍)。
  - 契約は 1 季節。切らなければ自動で続く (育った分 高くなる)。契約金 = 1,500 × (総合 ÷ 50)² × (1 + 得意の上乗せ)。季節の途中で手放すと違約金 (残りの分)。
  - レースに出るほど育つ。
- **整備の組**: 5 段。上げるお金 800 / 2,500 / 6,000 / 15,000。ピットをこなすと腕が上がる (段ごとに上限)。ピットで止まる時間 1.0 倍 → 一番よくて 0.6 倍。
- **知らせ** (`notify.ts`): 大会の前・研究が終わった・市場で売れた / 競りで抜かれた など。チームごとに 100 件・30 日まで。

### 2.20 お金・お店・市場

- ゲームのお金はチームの財布だけ (`accounts.money`)。使えるお金の上限なし。
- はじめのお金 1,000 (`inventory.ts`)。
- 使い道: 部品・研究・部品作り・進化・運転手の契約・整備の組・賭け。
- 入り方: 普段のレースの賞金・季節の賞金・大会の賞金・リーグ戦の毎日の賞金・チャンピオンの賞金・市場・賭けの払い戻し・ギフトコード・交換所。
- **お店**: 段階 1〜2 だけ。いつでも買える。1 回 50 個まで。値段の例: 運転席 300・骨組み 10・エンジン 250〜1,200・タイヤ 60〜220・タンク 40〜260・羽根 100 / 450・ブレーキ 60 / 220。
- **市場** (`shared/src/market.ts`):
  - 値段を付けて出す・競り の両方。出せる物: 部品・研究でできた部品・車の設計図 (写しを売る。売った人にも残る)。限界突破した部品と品は出せない。
  - 売れたら 5% の手数料。出品は 1 時間〜7 日 (はじめ 24 時間)。1 チーム同時に 20 まで。
  - 競りは前より 5% (最低 10) 以上高く。入れたお金はその場で預かり、抜かれたら戻る。
  - **部品の供給の約束**: 研究したチームが、別のチームに季節の間、決まった値段と数の上限で部品を売る。
  - 終わった出品は 7 日見える。

### 2.21 走行点と交換所

`shared/src/racepoints.ts`・`server/src/racepoints.ts`・`web/src/ui/exchange.ts`。

- 自分で走ったレースだけでたまる点。
- すぐ走る・部屋: 自分で走った 1 台目だけ。(完走 10 + 1 位 5・2 位 4 … 5 位 1) × 周の倍率。
- 大会: 自分で走ったとき同じ式。1 日の上限の外。
- 1 周アタック: 確かめが通った周に 1・自分の週の記録を縮めたら 5。
- リーグ戦・代走・雇った運転手の 2 台目は 0。
- 1 日 (日本時間) の上限 150 (レースと 1 周アタック)。ギフトコードと景品の走行点は上限の外。
- 交換所のはじめの品: 限界突破のかけら 600 (週 3)・指導のかけら 500 (週 3)・研究を 3 時間進める 120 (週 5)・進化の資金 3,000 円 150 (週 5)・紋章 2 つ 各 400・称号「走りこみ職人」800・「サーキットの主」3,000。

### 2.22 賭け (ゲームのお金だけ)

`shared/src/betting.ts`・`server/src/bets.ts`・`bets_league.ts`・`bets_tour.ts`・`web/src/ui/bets.ts`。

- **大事な決まり**: 賭けに使えるのはゲームの中のお金だけ。本物のお金で買える物・本物のお金に戻せる物は使えない。部品や品も賭けられない。
- 本物のお金 (課金) を入れたら、管理者の数 `realMoneyEnabled` を入にする。入の間は賭けの受け口が全部断る (見直しと法律の確かめが済むまで)。
- 賭ける先:
  - リーグ戦の 2 時間ごとのレース (全部コンピューターが走るので八百長できない)。自分のチームが出るレースには賭けられない。
  - 大会の優勝 (A 組の 1 位)。組が決まってからスタートまで。自分のチームが A 組にいる大会は不可。倍率は予選のタイム (なければ強さの見込み) から。
- 賭け方: 1 着当て (車ごと)・3 着以内 (車ごと)・2 チームの順番 (チームの前の車で比べる)・大会の優勝。
- 倍率 = (1 − 胴元の取り分 10%) ÷ 勝つ見込み (1.01〜200 倍)。見込みは試走台の 1 周・運転手の上手さ・慣れ・スタートの並びから。みんなの賭け方では動かさない。賭けた時の倍率で決まる。
- 締め切りはスタートの 5 分前。一番少ない賭け 1。上限なし (管理者があとから付けられる: 1 回・1 日・手元のお金の割合)。
- 返すとき: レースが計算できなかった・選んだ車が出なかった・6 時間たっても結果がない。
- お金を動かすのはアカウントの DO だけ。倍率はリーグの DO が出し、アカウントの DO がもう一度確かめる。

### 2.28 アカウント

### 3.3 サーバー (`server/src/`)

**Worker** (`worker.ts`)

- `/health` → "ok"
- `/api/league…`・`/api/bets…` → LeagueDO
- そのほかの `/api/…` → AccountsDO
- `/ws` → RaceRoomDO (WebSocket だけ)
- それ以外 → 画面のファイル (`web/dist`、Workers Assets。知らない道は SPA として index.html)
- `scheduled` (cron) → LeagueDO を `poke` で起こすだけ

**Durable Object**

| クラス | 数 | 役目 |
|---|---|---|
| `RaceRoomDO` (`worker.ts`) | 部屋ごとに 1 つ | 1 つのレースの部屋。中に `RaceRoom` (shared/room.ts) を持つ。WebSocket Hibernation で受け、50 ms の刻みはレース中だけ回す。待合と結果は alarm で起きる。段階が変わるたびに部屋の様子を storage に残し、眠ったあとに戻す。結果が出たら AccountsDO に RPC で送る |
| `AccountsDO` (`accounts_do.ts`) | 全員で 1 つ (名前 "accounts")、SQLite | アカウント・持ち物・設計図・財布・1 周アタック・チーム (運転手・整備・研究・市場・知らせ)・季節と大会・管理者の数・みんなのコース・開いた部屋の一覧・ギフト・賭けのお金・走行点。alarm で研究の終わり・市場の締め切り・季節の締め・大会の組の部屋を開く |
| `LeagueDO` (`league_do.ts`) | 全員で 1 つ (名前 "league")、SQLite | リーグ戦。cron で枠を積み、alarm 1 回で 1 レース (か日の締め) を計算する。賭けの倍率もここ。チームの様子・賞金・育ちは AccountsDO に RPC で頼む (届かなければ「送る箱」から送り直す) |

RaceRoomDO の名前の付け方:

- すぐ走る: `quickRoomId(級, 周, n)` (n は満員のときの次の部屋)
- 開いた部屋: `custom-<部屋の id>` (AccountsDO が `/api/rooms` で開いたときに `setupCustom` で作る)
- 大会の組: `tour-<大会の id>-<組>` (AccountsDO が組を作ったときに `setupTournament` で作る)

AccountsDO の中は、表ごとに受け持ちのファイルが分かれている (同じ SQLite に表を足す)。

| ファイル | 受け持ち |
|---|---|
| `api.ts` | 受け口の振り分け・ログイン・登録・持ち物・お店・設計図・パスワードを戻す |
| `accounts.ts` `crypto.ts` | アカウント・ログイン・持ち物・財布・設計図の保存 |
| `team.ts` | チーム・運転手・整備・研究・進化・限界突破・市場・知らせ |
| `season.ts` | 季節・級・大会・チャンピオン・はんこ・管理者の数 |
| `admin_config_log.ts` | 管理者の数の変更の記録 |
| `admin_players.ts` | 止める・招く |
| `timeattack.ts` | 1 周アタック |
| `tracks.ts` | みんなのコース |
| `rooms.ts` | 開いた部屋の一覧 |
| `gift.ts` | ギフトコード (中身を当てる `GIFT_APPLY`) |
| `items.ts` | 限界突破の品 |
| `racepoints.ts` | 走行点と交換所 |
| `bets.ts` `bets_tour.ts` | 賭けのお金・大会の優勝の賭け |
| `league_accounts.ts` | リーグの DO に渡すチームの様子 |

LeagueDO の中: `league.ts` (保存と進め方と受け口)・`bets_league.ts` (リーグ戦の賭けの受け口と倍率)。

`api.ts`・`accounts.ts` などは Cloudflare に頼らないので、試験でそのまま動かせる。

**cron と alarm**

- cron は `0 1-23/2 * * *` (UTC の奇数時 = 日本時間の 0・2・4…22 時)。置いたときだけ効く (手元の wrangler dev では動かない)。
- LeagueDO は cron の控えとして、自分でも次の枠のあとに alarm で起きる。
- 季節の締め・毎日の大会・研究の終わりなどは AccountsDO の alarm (次に進めることがある時刻に置き直す)。呼ばれたときにも進める (寝ている間の分もまとめて)。
- 無料の CPU の上限に合わせ、1 回の呼び出しを短くする (リーグ戦は 1 レースずつ。1 レース 8 台・5 周で 約 60〜120 ms)。

### 3.5 画面とサーバーのやりとり (レース)

WebSocket の JSON。形は `shared/src/protocol.ts`。

**入り口**

- すぐ走る: `/ws?laps=2|5|10&n=0&cls=<級>`
- 開いた部屋: `/ws?room=<部屋の id>`
- 大会の組: `/ws?tour=<大会の id>&g=<組>`

**画面 → サーバー (`ClientMsg`)**

| t | 中身 |
|---|---|
| `hello` | 機械の key・名前・設計図・ログインの合い言葉 (あれば) |
| `ping` | 時計合わせ (4 秒ごと) |
| `state` | 自分の車: 位置・向き・速さ・道のり・燃料・周・一番速い周・罰・タイヤと減り・破裂・ピットの道・作業中・傷み・DRS・オーバーテイク・MT・タイヤの組。0.1 秒ごと |
| `go` | 発進した時刻 (フライングの確かめ) |
| `finish` | ゴールの時間と周 |
| `retire` | リタイア |
| `start` | 開いた部屋で、開いた人が待合を早めに終える |
| `order` | 2 台目への作戦の合図 |

**サーバー → 画面 (`ServerMsg`)**

| t | 中身 |
|---|---|
| `welcome` | 自分の id・サーバーの時刻・部屋の段階・並び・整備の倍率・2 台目の名前 |
| `roster` | 並び (名前・設計図・色・場所・コンピューターか・2 台目の持ち主) |
| `phase` | 段階・コース・周・終わりの時刻・信号の時刻・天気の予定・結果 |
| `snap` | 全部の車 (0.1 秒ごと)・旗・止まる場所の空き |
| `resume` | つなぎ直したときの自分の車の続き |
| `info` / `error` / `full` / `pong` | 知らせ・断り・満員・時計 |

`snap` の 1 台は配列: `[id, x, y, 向き, 道のり, 印, 周, 速さ x, 速さ y, タイヤ, タイヤの周, ピットの回数]`。印はビットで、1 ゴール・2 リタイア・4 コンピューターが代わり・8 ピットの道・16 DRS・32 壊れた部品・64 破裂・128 止まっている・256 オーバーテイク。

**だれが計算するか**

- **人の車は人の画面が計算する** (1/60 秒の物理)。位置を 0.1 秒ごとにサーバーへ送り、サーバーはそれを信じて並べる (身内向けの仮の形。広げる前にサーバーでの確かめを強くする)。
- コンピューターの車・通信が切れた人の車・2 台目・代走・旗と SC は、サーバーの部屋 (`RaceRoom`) が計算する。
- ぶつかりは、それぞれが自分の側だけ直す (自分の画面で自分の車、サーバーでコンピューターの車)。少し遅れた相手の位置を使うので、ずれることがある。
- 天気・コース・走る線は種と決まった計算なので、画面とサーバーで同じになる。
- ゴールの時刻は 5 秒以上ずれていたらサーバーの時計を使う。

**レースのあと**

- RaceRoomDO → AccountsDO: `recordRace` (季節の点・賞金・はんこ・走行点)・`recordTeamRace` (2 台目・整備・研究・運転手の育ち・慣れ)・`recordTournamentGroup` (大会の組の結果)・`recordTrackRaceRuns` (みんなのコース)。同じレースは 1 回だけ数える。
- 払った賞金と走行点は `info` で 1 つの知らせにまとめて送る。

### 3.6 保存

- **画面 (この機械)**: `localStorage` に設計図・版・幽霊・走る前の準備・設定・ログインの合い言葉 (`web/src/store.ts`・`api.ts`)。ログインしていれば設計図はサーバーとも合わせる。
- **サーバー**: AccountsDO と LeagueDO の SQLite。お金と部品の数は `await` をはさまず 1 つの取りまとめ (transaction) で動かす。お金の出入りは `wallet_log` に残す。
- 部屋の DO は storage に部屋の様子 1 つだけ (眠ったあとに戻す用)。

### 3.7 試験と型

- `npm test` = `vitest run`。速いので全部回してよい。試験は `shared/test/` (51)・`server/test/` (15)・`web/src/**/*.test.ts` (3)。
- 重い試験 (8 台のリーグ戦のレースなど) は 1 つ 3〜4 秒。待ちは 20 秒。
- `npm run typecheck` = `tsc -p shared && tsc -p web && tsc -p server`。
- GitHub Actions (`.github/workflows/test.yml`): main への push と PR で、Node 24 で型と全部の試験。
- 試験で確かめている主なもの: 部屋の流れ・物理の手ざわり・コンピューターの速さ・実在のサーキットを 1 周走れること・リーグ戦の 1/20 秒の刻みのずれ・季節の締め・賭けの倍率・管理者の数の説明の足し忘れ (`adminconfig_meta.test.ts`) など。

### 3.9 置く (deploy) と公開の写し

- 本番はレース用のアカウントの Cloudflare (workers.dev)。URL はユーザーにだけ伝える (公開は身内から)。
- 置き方は `scripts/deploy.sh` だけ: wrangler のログインが `wrangler.toml` の置き先のアカウントか確かめる → git の HEAD の写しで `npm ci` → 型 → 試験 → web を組み立てる → すぐ `wrangler deploy`。作業中のファイルは混ざらない。
- 決まり (ユーザー): 区切りごとに試験と型が通ったら、聞かずに本番へ置き直してよい。ただし wrangler login / logout はユーザー本人だけ。
- `scripts/publish-public.sh`: 公開用の写しのリポジトリに HEAD の中身を送る。履歴は持っていかない。個人のメールアドレスと機械のフォルダの場所を消してから送り、残っていたら止まる。
- 本番の管理者の ID は、ユーザーが本番で登録してから決める (wrangler の secret)。

### 5.3 気づいている問題

- つづら坂の大雨で燃料切れが多かった (コンピューターの雨用タイヤの持ち方を直したが、釣り合いは見直す)。
- キーを決まった長さで押すだけの人は、よく回るぶん モナコで少し行きすぎる (試し遊びで確かめる)。

- ジェッダはほとんど全開なので、マニュアルで早めに変えてもあまり遅くならない。
- コースを足すと回し方がずれる。足すときは必ず置く日より後の月曜 0 時から (`TRACK_ROTATION_FROM`)。
- 上の部のリーグが 1 つで下が 3 つのときは、上のリーグの人が 2 人とも同じ日に下がることがある (ユーザー了承済み)。
- リーグ戦の alarm 1 回の CPU 時間は、本番で `wrangler tail` で見て、近ければ分ける。
