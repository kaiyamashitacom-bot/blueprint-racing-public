# Blueprint Racing

上から見る 2D の車のレース。マス目に部品を並べて自分の車を作り、ネットで大勢と走る。
ブラウザで動く (iPhone・Android・Mac)。決めごとの全部は [design/DECISIONS.md](design/DECISIONS.md)。

## 遊び方

1. **車をつくる**: マス目に部品 (運転席・エンジン・燃料タンク・タイヤ・羽根・ブレーキ・骨組み) を置く。全部の部品が運転席からたどれること。重さ・重心・タイヤの位置で走りが変わる。試走台で性能を見られる
2. **練習・1 周アタック**: ひとりで好きなだけ周回 (幽霊つき)。1 周アタックは週ごとの記録
3. **すぐ走る・部屋**: 短い (2 周)・普通 (5 周)・長い (10 周)。空きはコンピューターが埋めて 8 台。部屋を開いて人を招くこともできる
4. **チーム**: 2 台目の運転手を雇う・整備の組 (ピットが速くなる)・研究 (段階 3〜5 の部品)・市場 (部品と設計図の売り買い)・お店
5. **リーグ戦・季節・大会**: 2 時間ごとの自動のレース (本人がいなくても代走が走る)、級と季節の順位、予選つきの大会 (乾いた路面では乾いたタイヤを 2 種類使う決まり)
6. **コースづくり**: 線を引いて自分のコースを作り、1 周走ってから公開を申し込める

## 走るときの操作

- 操作は設定で選ぶ: **ふつう** (アクセルとブレーキも自分で) か **かんたん** (アクセル自動・曲がりの手前で自動ブレーキ)
- パソコンだけ **マニュアル** の変速も選べる (X / Shift で上げ、Z / Ctrl で下げる。上手に変えると少し速い)
- Mac: ← → (A D) で曲がる・↑ (W) アクセル・↓ (S・スペース) ブレーキ。スマホ: 画面の下のボタン
- **E** DRS (決まった区間で前の車と 1 秒以内)・**Q** オーバーテイク (押している間、目盛りを使う)・**P** ピットの予約・**R** 作戦係の無線のすすめを受ける
- 信号が全部消えたら発進。早すぎるとフライング
- タイヤは減り、天気で路面が濡れる。ピットでタイヤ・燃料・修理。壁に当たると部品が傷む。旗・SC・VSC もある
- 通信が切れたらコンピューターが代わりに運転する。つなぎ直せば続きから

## 動かし方 (Mac)

```bash
npm install
npm run dev
```

- 画面: http://localhost:5273 (同じ Wi-Fi のスマホからは `http://<Mac の IP>:5273`)
- サーバー: 8797 (wrangler dev、Mac の中だけ)
- 試験: `npm test`、型: `npm run typecheck`

## 仮にしてあること

- 部品・お金・賞金・車の動きの数は、試しながら合わせる前提の仮の数。管理者の画面で変えられるものもある
- 人の車の位置は人の画面が計算して送る (身内向け)。広げる前にサーバーでの確かめを強くする
